# Welcome aboard! 🚢

This is your **VirtualShip post-processing workspace**: a JupyterLab environment with the Python packages and tutorial notebooks needed to analyse and visualise your VirtualShip simulation results.

## Getting started

- Use the file browser on the left to explore the workspace. The tutorial notebooks are in the `tutorials/` folder.
- To work with your own results, upload them using the **Upload** button (↑) at the top of the file browser, or drag and drop them in.
- Double-click a notebook to open it, then run the cells with **Shift + Enter**.

## Good to know

- This workspace is **temporary**. It will shut down after a period of inactivity and anything you have created or uploaded will be lost, so remember to download anything you want to keep (right-click a file → **Download**).

## Need help?

Full instructions are available in the [VirtualShip documentation: Post-processing Workspace Guide](https://virtualship.readthedocs.io/en/latest/user-guide/tutorials/binder_guide.html).
