# Welcome aboard! 🚢

This is your **VirtualShip simulation workspace**: a cloud-based environment with `VirtualShip` and its dependencies already installed, ready for you to plan and run your virtual expedition.

## Getting started

- Open a terminal via the menu (**Terminal → New Terminal**) if one is not already open at the bottom of the screen.
- Check everything is working by running:

  ```bash
  virtualship --help
  ```

- Use the file explorer on the left to browse, create and edit your expedition files.

## Good to know

- This workspace runs in the cloud and will pause after a period of inactivity. Your files will persist between sessions.

## Need help?

Full instructions are available in the [VirtualShip documentation: Simulation Workspace Guide](https://virtualship.readthedocs.io/en/latest/user-guide/tutorials/codespaces_guide.html).
